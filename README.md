# meter-nmi-paper

Reproducibility package for **"Pretrained psychometric inference transfers
across instruments and populations"** (Nature Machine Intelligence
submission). METER is a pretrained neural-psychometric inference system:
compact modules trained only on simulated ordinal measurement worlds,
constrained by explicit graded-response decoders, applied with FROZEN weights
to real instruments and populations.

This repository is the paper's reproduction surface, not the research
codebase. It contains exactly what is needed to:

1. load the exact frozen paper models (hash-asserted on every load);
2. perform frozen inference on a response matrix — no target-dataset fitting
   exists anywhere in this package;
3. read and run the structured graded-response decoding step
   (`meter_reference/grm_decoder.py`);
4. reproduce the real-data evaluation metrics, given legitimate access to the
   source datasets (`evaluations/`);
5. reproduce the paper's numerical figure panels and Table 1 from the frozen
   aggregate artifacts (`python figures/reproduce_figures.py`);
6. verify that every released number corresponds to the frozen paper
   checkpoints (`pytest tests/`).

## Quick start

```
pip install torch numpy pytest
pytest tests/                      # full verification suite
python examples/synthetic_example.py
python figures/reproduce_figures.py
```

## API

```python
from meter_reference import load_model

model = load_model("meter-1d-paper")
result = model.score(X, mask=M)          # frozen 1-D scoring

model = load_model("meter-multidim-paper")
result = model.score(X, mask=M, factor_map=A)   # supplied-structure scoring
```

`result` carries scores, ordinal-only uncertainty, the capability-support
map, warnings and suppressions — or a refusal naming what was withheld and
why. Structure is an input, never an output: discovery requests are refused
with the frozen Milestone-7 closure reason. There are no training hooks,
optimizers or gradient paths in this package, and the test suite asserts that
scoring performs no parameter update.

## The frozen models

| id | canonical name (module) | params | state SHA-256 (prefix) | paper results |
|---|---|---|---|---|
| `meter-1d-paper` | **M-score** — single-construct scoring module (longitudinal-family architecture in single-wave mode) | 42,899 | `224a701b` | every real-data 1-D row: NHANES, ESS, SHARE, SAPA |
| `meter-multidim-paper` | **M-struct** — structure-conditioned multidimensional module (reproduced from a frozen seed, hash-asserted) | 30,986 | `8d427520` | MIDUS, IPIP-50, ICAR-16 rows |
| `meter-1d-synthetic-m4` | **M-ref** — one-dimensional reference core | 31,051 | `0d571638` | synthetic recovery r = 0.9388; uncertainty scalar |

The full audited lineage — training-world families, freeze dates, and the
per-analysis mapping — is in `MODEL_LINEAGE.md`. Two distinct 1-D modules
appear in the paper: M-ref for the known-truth synthetic benchmark, M-score
for all real-data unidimensional scoring.

Checkpoint identity is enforced twice: file hashes in
`checkpoints/CHECKSUMS.sha256` and the frozen STATE digests asserted inside
every loader (`paper_manifest.json` records both). The reliability output is
released as a **relative reliability indicator** (capability contract v3.6,
the preregistered P5 EXIT_2 relabel): within-result midrank percentiles of
the withheld posterior widths, usable ordinally only and never comparable
across separate calls; the interval scale is not calibrated on real data,
and that warning travels with every result. Versioned contract records live
in `contracts/` (v3.6 active, v3.5 archived; the frozen Fig. 4 router
evidence was executed under v3.5 and records that hash).

## What is absent

The synthetic measurement-world generators, all training code, and every
capability outside the paper (longitudinal trait-state analysis, multimodal
fusion, DIF, instrument linking, adaptive change detection, structure
discovery). The paper's negative results about those boundaries are shipped
as frozen artifacts (`derived_results/`), and the routing layer that enforces
them at runtime is included and verified (`tests/test_router_replay.py`).
Files under `src/human_measurement/` are verbatim copies of the frozen
research implementation except for six explicitly documented trims (see
`RELEASE_AUDIT.md`); the fixture tests prove bit-identical inference against
outputs generated by the original frozen stack.

## Real data

No participant-level data is present anywhere in this repository, and none
may be added. Each `evaluations/<dataset>/README.md` records where authorized
researchers obtain the source data, the licence and AI-use restrictions in
force (which several custodians impose — read them), the expected input
schema, and the frozen analysis procedure.
