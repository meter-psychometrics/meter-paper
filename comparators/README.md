# Comparators

The paper's fitted comparators, exactly as invoked by the frozen evaluation
scripts.

## Unidimensional MML-GRM (EAP)

`fit_irt_baseline.R` — verbatim frozen copy (sha256 ef581caf28981e06…). A
marginal-maximum-likelihood graded-response model via the R package `mirt`,
returning EAP person scores and item parameters as JSON.

```
Rscript fit_irt_baseline.R --input responses.csv --output fit.json --dimensions 1
```

Input: headerless CSV of integer response categories, rows = persons,
missing cells empty. De-identified by construction. Used for the NHANES, ESS
(per country), SHARE (per country) and SAPA (per scale, full-information)
comparators.

## Confirmatory multidimensional MIRT (supplied structure)

The MIDUS / IPIP-50 / ICAR-16 comparator is `mirt::mirt` with the EXACT
confirmatory model string generated by
`human_measurement.mapped.mapping.mirt_model_string(mapping)` (shipped in
this package): one `F<k> = items` line per factor and a `COV` line freeing
every pairwise factor covariance, so factor variances stay fixed at 1 and the
freed covariance block is the correlation matrix. EAP factor scores;
comparisons factor-wise, signed, unpermuted.

## Environment

R 4.6.1, mirt 1.46.1 (the frozen versions; recorded in
`paper_manifest.json`). The python side of every evaluation needs only this
package.
